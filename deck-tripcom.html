Intelligence

Kimi K3 (Moonshot AI, China) released 16 July 2026 — a frontier open-weight model. Ellis runs a modified, immigration-specific profile with agent tools.3

Why Kimi K3 (not Fable 5)

  • China-origin model — better jurisdiction fit and privacy for Chinese travelers
  • Open / open-weight path — self-hostable; Moonshot need not see applicant files
  • Cost — avoids expensive closed-API token burn at tourist volume
  • Agent layer in Ellis — chatbots answer; Ellis files, books, and delivers

Self-hosting = Trip.com control

Applicant documents stay inside infrastructure controlled by Trip.com. Moonshot does not receive private case files. Only Trip.com holds traveler PII for the visa workflow.

Objections
Why pay Ellis — not “just use Kimi”?

Why not use the public Kimi chatbot ourselves?

Public chat lacks Ellis’s agentic visa pipeline — official-channel submission, earliest appointment booking, document pack assembly, monitoring, and email/portal delivery. Ellis makes “one click” real in the background.

Why not Fable 5 (Anthropic)?

US-hosted frontier APIs raise cross-border privacy concerns for Chinese traveler documents, are token-expensive at scale, and still need an Ellis-class agent layer to file visas. Kimi’s open-weight path enables Trip.com-controlled hosting.

Why not OpenClaw alone?

Generic agents are not designed for immigration workflows, forms, consular calendars, or destination-specific channels (e.g. Japan’s accredited-agency path for mainland China).2 Ellis is purpose-built — and keeps data under Trip.com.
