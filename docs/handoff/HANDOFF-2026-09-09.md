## Data model and doctrine (do not break these)
- One cached answer per route in table kimi_route_guidance_cache. Key = nationality|nationality|destination|purpose|jurisdiction|unknown|v6, plus `|via:XXX` for stopovers and `|doc:type` for non-ordinary passports. A travel date and the residence country never fork the key (kimi_primary.cache_key, is_canonical_key, canonical_key).
- Verified facts live in data/database_seed/verified_overrides.json (one entry per route key, gov-domain source_url required, verbatim quote in the note) and /var/lib/ellis/operator_overrides.json on the server (console edits). They merge onto the model answer at read time (verified_overrides.apply). A verified requirement_detail implies its verdict. enforce_verdict_invariants makes a served answer consistent with its verdict.
- Dispositions: VISA_REQUIRED, VISA_EXEMPT, VISA_ON_ARRIVAL, ELECTRONIC_AUTHORIZATION_REQUIRED, CONDITIONAL. requirement_detail vocabulary: unconditional_visa_free, conditional_visa_free, transit_visa_free, evisa, paper_visa, evisa_on_arrival, paper_visa_on_arrival, eta_electronic_authorization. kimi_primary.DETAIL_FAMILY says which details belong to which verdict.
- kimi_primary.serve_time_invariants(guidance) is the one deterministic contradiction check, run at generation and on the final merged answer. Contradictions hold the answer from readers (review_required, held) until a person verifies the verdict.
- Confidence ladder (Trip.com standard 4.2.3): High = verified against a named official page, complete, no conflict. Medium = official source with gaps. Low = never shown to readers ("we are checking this route").
- Official sources only, government domains only (authority.is_government_host). Never bypass CAPTCHAs or bot challenges. Never invent a fee, stay or validity. A blank cell is "not published", "does not apply" or "missing", never a guess.
- A failed page read never erases the last good check (freshness._stamp, effective_check). A stale answer is never regenerated from the model's memory (refresh_stale_async files an issue instead).
- Style for anything the owner or Trip.com reads: plain, conversational, no em dashes, minimal hyphens, extremely concise.
