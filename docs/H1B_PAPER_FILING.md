# H-1B I-129 Paper (Mail) Filing — verified 2026-08-09

Paper filing is fully permitted in 2026 for H-1B extensions and amendments;
online filing is optional, never mandatory. Ellis offers BOTH paths as
first-class: an online-filing prep and a mail-ready paper packet. Re-verify
the lockbox address on uscis.gov/i-129-addresses AT PACKET-GENERATION TIME —
USCIS updates addresses annually (usually February). Sources were read via
search excerpts (uscis.gov 403-blocks direct fetch); revalidate before the
first real mailing.
